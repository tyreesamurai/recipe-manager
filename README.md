# Recipes

A personal recipe manager for the household. Store recipes, browse them, and generate shopping lists when you're ready to cook.

## What it does

- **Browse recipes** — the home page lists everything in the database. Filter by name, cooking time, or calories to find what you're looking for.
- **Recipe pages** — each recipe has its own page with instructions, ingredients, and nutrition info if available.
- **Create & edit** — add new recipes through a tabbed form (basics, instructions, ingredients, details). Edit existing ones from the recipe page.
- **Shopping cart** — select recipes from the home page and add them to your cart. When you're ready, generate a shopping list that consolidates all the ingredients.
- **Meal planner** — coming soon.

## Stack

Next.js, Drizzle ORM, PostgreSQL, Tailwind CSS, shadcn/ui.
